# Power Manager

Утилита для перезагрузки / выключения Windows-ПК — с таймерами, без лишних
подтверждений. Требует права администратора.

## Возможности (v2)

- **Таймеры выключения/перезагрузки**: сейчас (без задержки), через 10 с,
  30 с, 1 мин, 5 мин, 10 мин, 30 мин, 1 час.
- **Без подтверждения**: действие запускается сразу после нажатия кнопки.
- **Отмена завершения**: кнопка «Отменить завершение» (`shutdown /a`)
  останавливает уже запланированное завершение — например, если вы выбрали
  таймер и передумали.
- **Права администратора**: требуются (манифест UAC `requireAdministrator`
  встроен в exe; при запуске из исходников без прав программа сама
  перезапрашивает повышение через UAC).
- Статусная строка показывает обратный отсчёт до запланированного действия.

## Состав

| Файл | Назначение |
|---|---|
| `power_manager.py` | GUI-приложение (tkinter, входит в Python) с кнопками и таймерами |
| `make_icon.py` | Генератор иконки `power.ico` (только stdlib, без зависимостей) |
| `power.ico` | Иконка приложения (многоразмерная, PNG-входы) |
| `PowerManager.spec` | Конфигурация сборки PyInstaller (onefile, windowed, UAC admin) |
| `dist/PowerManager.exe` | Standalone-сборка (PyInstaller, onefile, без консоли) |

## Запуск из исходников

```bat
python power_manager.py
```

Требуется только Python 3 с tkinter (стандартная поставка Windows).
При запуске без прав администратора программа покажет запрос UAC
и перезапустится с повышением.

## Сборка standalone .exe

```bat
pip install pyinstaller
python -m PyInstaller --noconfirm --clean PowerManager.spec
```

Либо одной командой (создаст свой spec):

```bat
pip install pyinstaller
python -m PyInstaller --noconfirm --onefile --windowed --uac-admin ^
  --name PowerManager ^
  --icon power.ico ^
  --add-data "power.ico;." ^
  power_manager.py
```

Результат: `dist\PowerManager.exe` — запускается на любом Windows-ПК
без установки Python. Манифест UAC (`requireAdministrator`) требует прав
администратора при каждом запуске.

## Как работает

- «Перезагрузка по таймеру» → `shutdown /f /t N /r`
- «Выключение по таймеру» → `shutdown /f /t N /s`
- «Отменить завершение» → `shutdown /a`

`N` выбирается в списке таймеров; для варианта «Сейчас» `N = 0`.
`/f` принудительно закрывает незавершённые приложения.
Подтверждение перед выполнением **не** запрашивается.
